Each currency is an index built from the 7 pairs it shares with the other majors: every pair's M15 log return is signed (+base / −quote) and averaged with weight 1/8 (the eight-currency zero-sum construction), then accumulated from a common base of 100. Candles are the index path over the selected period; highs/lows are sampled at M15 resolution (intrabar synthetic extremes are not claimed). Breadth counts the actual oriented pair returns and is not 7 independent confirmations. Relative measure only — no absolute value, no combined strength score. This is a research / pair-selection tool — not a trade signal, probability, or evidence of profitability, and it places no orders. Developing views: day = UTC calendar day from 00:00, week from Monday 00:00 UTC, month from the 1st 00:00 UTC — each through the latest completed M15 (forming candle excluded). Times shown in EAT (UTC+3) with UTC alongside.
